# ROS 2 Lab 2 – Turtlesim, Topics, and Services

## Description

In this lab, the ROS 2 environment was set up and the Turtlesim node was launched to simulate a robot. The turtle was controlled using keyboard inputs through the teleoperation node.

ROS 2 topics were explored by listing active topics and observing the turtle’s position in real time. Velocity commands were also published to control the turtle’s movement. A service call was used to reset the simulation.

The rqt tool was used to visualize nodes, topics, and services. Using rqt, the `/reset` and `/spawn` services were called to reset the simulation and create a second turtle. The second turtle was controlled independently using its command topic.

Overall, this lab provided a basic understanding of ROS 2 communication using nodes, topics, and services, along with real-time robot control.
